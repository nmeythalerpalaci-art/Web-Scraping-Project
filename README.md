# Web Scraping Project — Virginia Tech BIT

## Overview

A Python web scraper developed in Google Colab to extract faculty directory information from Virginia Tech's Business Information Technology (BIT) department.

## Data Collected

- Faculty names and titles
- Email addresses and phone numbers
- Office locations
- College and department information
- Faculty profile links

## Technologies

- Python
- Requests
- BeautifulSoup
- Pandas
- CSV

## Output

The extracted information is organized into a CSV file for structured data storage and further analysis.

## Skills Demonstrated

- Web scraping
- HTML parsing
- HTTP requests
- Data extraction
- Data organization
- CSV file generation

## How to Run

1. Open the Jupyter Notebook in Google Colab.
2. Run the notebook cells in order.
3. Review the extracted directory information.
4. Export the results to a CSV file.

## Project Purpose

This project demonstrates practical Python programming skills and the ability to automate data collection and organize structured information from web pages.
