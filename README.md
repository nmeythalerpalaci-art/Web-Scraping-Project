# Web-Scraping-Project— Virginia Tech BIT

Overview
A Python web scraper developed in Google Colab to extract faculty directory information from Virginia Tech's Business Information Technology (BIT) department.

Data Collected
Faculty names and titles
Email addresses and phone numbers
Office locations
College and department information
Faculty profile links

Technologies
Python Libraries: Requests, BeautifulSoup, Pandas, and CSV

Output
The extracted information is organized into a CSV file for structured data storage and further analysis.

Skills Demonstrated
Web scraping, HTML parsing, HTTP requests, data extraction, and CSV file generation.****
